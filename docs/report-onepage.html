Chat filter: one two-letter rule censors thousands of ordinary words

Ragnarok: Rebirth Global  ·  measured against the live service  ·  11 September 2026
The filter blocks the two-letter sequence cu and matches it as a raw substring. Every word containing those letters is refused, in every language.

5,928 test messages were sent to the live service. 693 ordinary dictionary words were confirmed refused; 4,462 were confirmed to pass. Each headline word above was re-tested three times and blocked every time.

Why it happens

cu is vulgar in Portuguese. It appears to have been added for that market, but it is matched as a substring against all eight languages the title ships in.

The result is that a single two-letter entry censors ordinary vocabulary everywhere, including Portuguese itself — where it does the most damage.

It is also missing what it should catch

Tested against the same live service: kike, spic, fag, rape, whore, bitch, dick and slut all pass unmodified. Spaced-out evasion is caught for some terms (s h i t is blocked) but not others (f u c k passes). Correcting the matching improves accuracy in both directions — this is not a request to moderate less.

Recommended fix

1  Immediate. Remove cu, or restrict it to Portuguese and to whole-word matching. This single change resolves the large majority of the false positives in every market.

2  Structural. Require a minimum length before a term may match inside a longer word, and scope each term to the locale it was added for. A two-letter entry should never match as a substring.

3  Supplied. A verified list of 693 ordinary words currently refused by your service, each confirmed by a live test message. Purely additive — it can only remove false positives.

Also included: the raw log of all 5,928 probes, so any single claim here can be traced to the message that established it.
