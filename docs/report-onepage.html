Chat filter blocks ordinary words

Ragnarok: Rebirth Global  ·  independent measurement against the live service  ·  12 September 2026
The filter searches for each banned word anywhere in a message, including inside longer words, and the word list is mostly Brazilian Portuguese. Its short entries are applied to all eight languages the game ships in, so the filter blocks ordinary words in every one of them.

The shortest demonstration

a player types  thank  →  the message is delivered
a player types  thanks →  the message is blocked
adding one letter creates ks, which is on the word list

The rule is two characters, matched anywhere

cu  blocked    xxcuxx  blocked    xxcxx  ok    xxuxx  ok    xxucxx  ok
ks  blocked    xxksxx  blocked    xxkxx  ok    xxsxx  ok    xxskxx  ok

The filter blocks these letters on their own, and again inside a made-up word, at any position. It delivers each letter on its own, and delivers the same two letters reversed. The filter delivered 10,627 words during this audit, and none of them contains cu or ks.

All 27 Portuguese terms tested are blocked, including arrombado and otario. The filter is not over-aggressive in general — it is aggressive about one language's vocabulary and largely absent for another's. One root cause: a term list never reviewed against the locales it is applied to.

Three ways to fix it, in increasing effort

1  Allow the confirmed words. findings/words-to-allow.txt lists 343 ordinary words confirmed blocked, each annotated with the rule responsible. If the filter already supports an exception list, this is a data change and nothing else — it removes false positives only.

2  Require a word boundary for short terms. One rule — entries shorter than five characters match only as whole words — removes most of the problem. The filter still blocks a message that is only the word cu, and stops blocking document. Entries of five characters or more are not affected.

3  Replace the matcher. engine/ — per-term match modes, severity tiers, allowlist rescue, evasion folding. No dependencies, MIT, 55 tests and 29 conformance vectors, at the same check(text) seam as today's filter.
